# A. 前回 NG だったもの

## A-1. プラン切り替えで落ちない → 広告で固まらない

**前回「中間レイヤーは発動しているが操作できない」とご報告いただいた件です。**

原因は広告そのものではなく、広告の背後に敷く**黒い全面レイヤー**でした。
これがタッチを全部吸収する作りで、広告が実際に表示されなかった場合に
**最大2分間アプリ全体がロック**されていました。

1. 記録の保存や AI 相談を何度か行う
2. 広告が出る場合 → 閉じたあと**普通に操作できること**
3. 広告が出ない場合 → **黒い画面で止まらないこと**（3秒以内に復帰）

## A-2. 画面切り替えの残像

**保留にしていた証明書画面の残像も、同じ原因だったはずです。**
押された画面が透明で、スライド中に下の画面が透けていました。

以下すべてで、切り替え時に前の画面が残らないこと:
- 予防医療 → プログラム名タップ（投与履歴）
- 証明書 → ＋ボタン（予防医療の一覧）
- 設定 → プランをアップグレード
- 投薬 → 予防医療の行タップ
- 健康の記録 → 明細タップ

## A-3. PDF プレビュー

1. AI健康レポート → PDF
2. **プレビューが表示されること**
3. 日本語が正しく出ていること
4. 圏外や機内モードで試すと、**固まらずエラーメッセージが出ること**

初回は日本語フォントを取得するため数秒かかります。その間ボタンは無効化
されます。

## A-4. ローディング

1. 起動直後・一覧の読み込み・証明書の表示
2. **回転していないこと**、中央に大きめのアイコン、下に「loading...」
3. 保存ボタンを押した瞬間の**ボタン内**は小さい丸のままです（意図的）

前回「小さいアイコンが回っている」とご指摘の箇所は、健康記録とトイレ記録の
**保存ボタン内でサイズ制約が無く**ボタン全体に広がっていたものでした。

# B. 改善・要望

## B-1. 排尿の表示

一覧の排尿行が **「色: 濃い / 量: 多い」** と `/` でつながること（排便と同じ形）。

## B-2. AI の残り回数

**AI相談・給餌量の、実行ボタンのすぐ下**に表示されること。

## B-3. 体重の並び替え

1. 体重の記録 → 一覧表示
2. ヘッダーの **↓/↑ ボタン**で新しい順・古い順が切り替わること
3. 増減（+0.2 等）が、並び順を変えても**常に「前回比」**になっていること

## B-4. 体重の修正・削除（トイレ記録と統一）

1. 行を**タップ** → 修正ダイアログ（日付・体重が入った状態）
2. 行末の**ゴミ箱ボタン** → 確認 → 削除
3. **長押しでは削除されないこと**（見えない操作だったので廃止）

**トイレ記録側にも確認ダイアログを足しました。** 指示範囲を少し越えて
います（削除ボタンがタップ可能な行のすぐ隣にあり、取り消しも無いため）。
不要であれば戻します。

## B-5. トイレ記録の ＋ ボタン

1. 一覧の上は **すべて／排尿／排便 の絞り込み**になったこと
2. 記録は右下の **＋** から
3. 入力画面の一番上で**排尿・排便を選べる**こと
4. 期間の絞り込み（1週間/1か月/3か月/すべて）と併用できること

## B-6. タブのスワイプ

1. 日々の記録・医療・AI相談の3画面
2. **左右スワイプでタブが変わること**
3. **戻ったときに状態が残っていること**（スクロール位置・入力途中の文字）

## B-7. キーボードを閉じる

どの入力画面でも、**入力欄以外のどこかをタップするとキーボードが閉じる**こと。

## B-8. ペット切り替え画面

ペット名をタップ → **編集画面**。行の他の場所をタップ → 従来どおり**切り替え**。

## B-9. 予防医療リマインダーの設定

1. 予防医療の記録 → リマインダーを ON
2. **「通知するタイミング」** に 当日／1・3・7・14日前
3. **複数選べること**（例: 当日 ＋ 3日前）
4. その下に**注意書き**が出ること
5. フィラリア薬で **「当日」だけ**を選べること

**設定しなければ従来どおり**です（ワクチン7日前・投薬3日前）。既存の記録の
挙動は変わりません。

# C. iOS ビルド後でないと確認できないもの

## C-1. Google ログイン（iPhone）

**原因はビルド構成の食い違いでした。** Codemagic は
`GoogleService-Info.plist` を本物に差し替えますが、コールバック用の
URLスキームを持つ `Info.plist` は、リポジトリ内のプレースホルダから
手書きされた**古い値**のままでした。ずれていると認証後にアプリへ戻れません
（Android は別の仕組みなので無関係）。

ビルド時に本物から読み取って書き込むようにしました。

1. iPhone で Google ログイン
2. ブラウザから**アプリに戻ってこられること**

**これは最有力の仮説であって、確証ではありません。** 直っていなければ、
Firebase コンソール側の iOS OAuth クライアント設定を次に見ます。

## C-2. Apple ログイン（Android）

`webAuthenticationOptions` が渡っておらず、Apple の Web フローが
**そもそも開始できていません**でした。iOS は OS に直接聞くのでこれを見ず、
同じボタンが動いていた、という差です。

1. Android で Apple ログイン
2. ブラウザが開き、認証後**アプリに戻ってこられること**

## C-3. iPhone のリマインダー（R4 の B-1・未確認）

1. 投薬か予防医療でリマインダーを ON、**数分後の時刻**に
2. アプリを閉じて待つ → 通知が来ること
3. **開いたままでも**来ること（こちらが修正した側です）

# D. 前回の未確認分（再掲）

## D-1. トイレの警告が1か月以内（R4 A-7）

血便疑いの記録を1件入れて、警告バナーが出ることだけ見てください。
1か月より古い記録では出なくなるのが修正点ですが、古い記録を作るには
日付を手で戻す必要があります。

## D-2. 証明書は種別ごとに最新だけ（R4 A-10）

同じ予防プログラムの証明書が複数あるとき、最新の1件だけになり、
「過去の証明書 ◯件は非表示です」と出ること。右上のフィルタで全部出ること。
狂犬病と混合ワクチンは別々に残ります。
