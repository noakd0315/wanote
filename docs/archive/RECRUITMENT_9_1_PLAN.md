# 0. 先に、日程の話

**9/1 は「余裕をもった目標」ではなく「最遅」です。**

```
9/1   配信開始
 +14日
9/15  Androidの14日条件を達成
 +数日  製品版アクセスの審査
 +数日  アプリ審査
─────
9/25前後  公開          ← 締切 9/30 まで 5日
```

**配信が1日遅れると、公開も1日後ろにずれます。** 9/1を守れないと
締切に間に合わない可能性が出てきます。

そして**審査は待ち時間で、短縮できません**。だから
**「募集」より「審査に出す」方を急いでください。** 募集は
リンクを配るだけですが、審査は出してから数日かかります。

# 2. Google フォームの項目

## 🔴 最重要の設定

**設定 → 回答 → 「メールアドレスを収集する」を「確認済み」にしてください。**

回答者のGoogleアカウントが**自動で記録されます**。手入力させると
必ず打ち間違いが出て、その人だけインストールできません。

**あわせて募集文に「テストに使うスマホから回答してください」と
書いてください。** PCの別アカウントで回答されると、記録される
アドレスが端末のものと食い違います。

## 項目一覧

| # | 質問 | 形式 | 必須 |
|---|---|---|---|
| — | （メールアドレス：自動収集） | — | — |
| 1 | お名前またはニックネーム | 記述式（短文） | ● |
| 2 | テストに使う端末 | ラジオ：Android / iPhone / 両方 | ● |
| 3 | 犬を飼っていますか | ラジオ：はい / いいえ | ● |
| 4 | 愛犬の頭数 | 記述式（短文） | |

**Android / 両方 を選んだ人だけに出す:**

| # | 質問 | 形式 | 必須 |

# 4. 集まったあとの流れ

## Android

1. フォームの回答から**メールアドレスの列だけ**をコピー
2. Play Console → テスト → クローズドテスト → テスター
   → メールリストを作成して貼り付け
3. 表示される**オプトインURL**を、回答者へメールで送る
4. 各自が「テスターになる」を押す → インストール
5. **12人以上がオプトインした日から14日**

> **15〜20人集めてください。** 12人ちょうどだと、1人抜けた時点で
> 条件を満たさなくなります。

## iOS

1. TestFlight の**パブリックリンク**を発行
2. 回答者へメールで送る（または投稿に追記）
3. 各自が TestFlight からインストール

> **審査が通ってからでないとリンクは配れません。** 8/25までに
> 提出しておく理由がこれです。
