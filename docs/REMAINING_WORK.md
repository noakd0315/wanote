## P-2. `support@wanote.jp` — あと MX 1行

**ここまで完了**

- メールアドレス `support@wanote.jp` の作成
- ネームサーバーを `dns1/dns2.onamae.com` に戻した
- **レジストリへの委任反映も完了**（`a.dns.jp` で確認済み）

**残っているのは MX レコード1行だけです。**

```
現状: MX preference = 0, mail exchanger = (root)   ← null MX（受信拒否）
必要: mail21.onamae.ne.jp / 優先度 10
```

**再開時にやること（順に）**

1. こちらで DNS を照会する（「確認して」で実行します）
2. `(root)` のままなら、お名前.com の **DNSレコード設定**で MX の行数を確認

   | 見えているもの | 対応 |
   |---|---|
   | `mail21.onamae.ne.jp` の1行だけ | 反映待ち。時間をおく |
   | `.` と `mail21...` の2行 | **`.` の行を削除**（null MX が優先され受信を拒否します） |
   | `.` の1行だけ | 追加が保存されていない。「確認画面へ進む」→「設定する」まで押す |

3. 通ったら **外部（Gmail等）から `support@wanote.jp` 宛にテスト送信**
   - Webメールからの自送信は**同一サーバー内で完結し DNS を参照しない**ため、
     確認にならない（2026-08-18 に実際にそうなりました）

**SPF は受信には不要です。** 送信したメールが相手側で弾かれるようなら、
そのとき `v=spf1` の指定を追加すれば足ります。

> **急ぎではありません。** ストア公開用の連絡先には、受信できる Gmail を
> 暫定で使えます。アドレスは後から変更できます。
> **届かないアドレスだけは公開しないでください。**
