**AI機能には上限があり、確認の途中で頭打ちになります。**

| | 上限 | リセット |
|---|---|---|
| AI相談・給餌量相談（合計） | **無料5回/月** | 翌月 |
| AI相談のリクエスト | 10回/時 | 1時間後 |

用意しますので声をかけてください**（`PRETEND_PREMIUM=true`）。
広告の有無も同時に変わるため、広告の確認は先に済ませてください。
