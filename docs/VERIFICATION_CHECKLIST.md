## A-2. 保存の完了が分かるか

**PM報告「保存できたか分からない」への修正です。** 順序を変えました。

```
保存 → 画面を閉じる → 「保存しました」 → 広告
```

## A-3. リマインダー

- [ ] 薬を登録し、**数分後**に設定 → 鳴るか
- [ ] **どれくらい遅れたか**（1分以内／数分／それ以上）
- [ ] アプリを**完全終了**しても鳴るか
- [ ] 🔴 **端末を再起動しても鳴るか**
