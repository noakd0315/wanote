### 写真と動画 → 写真

| 質問 | 回答 |
|---|---|
| 収集しますか | **はい** |
| 共有しますか | **いいえ** |
| 必須ですか | **任意**（写真なしでも記録できます） |
| 用途 | **アプリの機能** |
| 削除をリクエストできるか | **はい** |

> **証明書の画像は AI（Anthropic）へ送信されます。** これを「共有」と
> 申告すべきかは判断が分かれます。**Google の定義では、処理を委託する

> 迷う場合は「共有する」と申告した方が安全側です（過少申告の方が
> 問題になります）。

# App Store：App のプライバシー

Apple は「**あなたに関連づけられるデータ**」か
「**あなたに関連づけられないデータ**」かを分けて申告します。

**本アプリはすべてアカウントに紐づく**ので、
**「ユーザーに関連づけられたデータ」**として申告します。

## 申告する項目

| カテゴリ | 種類 | 用途 |
|---|---|---|
| 連絡先情報 | **メールアドレス** | App の機能 |
| 識別子 | **ユーザーID** | App の機能 |
| 識別子 | **デバイスID**（広告ID） | **サードパーティ広告** |
| ユーザーコンテンツ | **写真** | App の機能 |
| ユーザーコンテンツ | **その他のユーザーコンテンツ**（健康記録・メモ） | App の機能 |
| 購入 | **購入履歴** | App の機能 |

## 🔴 健康データの扱い（判断が必要）

Apple には「**健康とフィットネス**」というカテゴリがあります。

**本アプリが記録するのは犬の健康情報であり、利用者本人の健康情報では
ありません。** Apple の「健康」カテゴリは**人間の健康データ**を
想定しています。

**「健康」では申告しない**のが妥当と考えますが、**判断が分かれうる点**
なので、審査で指摘された場合は追加すれば済みます。

> **HealthKit は使用していません。** これは明確です。

## トラッキング

| 質問 | 回答 |
|---|---|
| トラッキングに使用しますか | **はい**（広告IDのみ） |
| ATT の許可を求めますか | **はい** |

> **ATT で許可されなくても全機能が使えます。** 表示される広告が
> 利用者に関連しにくくなるだけです。

# 🔴 申告前の確認事項

## 広告を入れないまま出す場合

**広告関連の申告をすべて取り下げてください。**

- 広告ID の収集 → **いいえ**
- ATT → **いいえ**
- Play の「広告が含まれます」→ **いいえ**

**現在は実装済み**ですが、本番の広告IDが未設定です（テストIDのまま）。
**テストIDのまま出荷すると、広告は表示されるが収益は発生しません。**
その場合でも「広告が含まれます」は**はい**で申告してください。

## 課金を有効にしないまま出す場合

**購入履歴の申告を取り下げてください。** RevenueCat が未設定なら
購入自体が発生しません。

# 根拠（コードで確認した事実）

| 主張 | 確認した場所 |
|---|---|
| 解析SDKなし | `pubspec.yaml` に Analytics / Crashlytics / Sentry が無い |
| 位置情報なし | 位置情報系の依存が無い |
| 生体情報は端末内 | `local_auth` は端末内で完結し、送信経路が存在しない |
| カード番号を受け取らない | 決済は `purchases_flutter` 経由でストアが処理 |
| AIへの送信は最小限 | `functions/src/routes/consultation.ts` / `report.ts` / `ocr.ts` |
| 他人のデータに到達不可 | `firestore.rules` / `storage.rules`（テスト77件・**本番環境でも実データで確認済み**） |
| アプリ内で削除可能 | 設定 → アカウントを削除 |
