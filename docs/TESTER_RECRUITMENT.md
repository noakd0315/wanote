# 3. 応募後の運用

## 集まった情報の扱い

**スプレッドシートは共有しないでください。** メールアドレスが並びます。

配布時は次のように使います。

| 端末 | 使う項目 | 登録先 |
|---|---|---|
| Android | Googleアカウントのアドレス | Play Console → 内部テスト → テスター |
| iPhone | Apple ID のアドレス | App Store Connect → TestFlight → 外部テスター |

## 人数の上限

| | 上限 |
|---|---|
| Play 内部テスト | **100人** |
| TestFlight 外部テスト | 10,000人（**Beta App Review が必要**） |
| TestFlight 内部テスト | 100人（審査不要。App Store Connect のユーザーに限る） |

> **Play の内部テストは100人まで。** それを超えるなら
> **クローズドテスト**に切り替える必要があり、審査が入ります。
