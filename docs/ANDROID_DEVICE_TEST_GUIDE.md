# Android 実機テストの手順と確認項目

> ## 🔴 課金のテストだけは、Play からダウンロードすること
>
> **`adb install` で入れたビルドでは購入できない。** 商品一覧も金額も正しく
> 出るので画面は正常に見えるが、購入した瞬間に Play が `ITEM_UNAVAILABLE`
> を返す（2026-08-21 と 2026-08-23 の2回、同じ壁に当たった）。
>
> ```
> package:jp.wanote.app  installer=null      ← Play 経由ではない
> ErrorCode: ITEM_UNAVAILABLE
> ```
>
> **Play は自分が配信していないアプリからの購入を受け付けない。** 署名も違う
> ── ローカルビルドは**アップロード鍵**、Play が配信する版は Play App Signing
> で**アプリ署名鍵**に付け替えられている。
>
> | 確認したいこと | 入れ方 |
> |---|---|
> | 画面・機能・不具合 | `adb install` でよい（速い） |
> | **購入・課金** | **内部テストのリンクから Play ストア経由で入れる** |
>
> 購入をテストしたあと `adb install` で上書きすると、**また買えなくなる。**

## つまずいたときは

| 症状 | 対処 |
|---|---|
| **`Device ... is not authorized`** | **実際に起きたのはこれです。** 下の「認証が通らないとき」へ |
| `flutter devices` に出ない | USBケーブルが充電専用の可能性。データ転送対応のものに替える |
| 同上 | 端末の通知シェードで**「USB接続の用途」→「ファイル転送」**に変更 |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | 端末に古い版が入っている。アンインストールしてから再実行 |
| 起動直後に落ちる | **Firebase 接続の問題の可能性が高い**。`flutter run` の出力をそのまま貼ってください |
| 通知が鳴らない | 端末の「電池の最適化」でアプリが制限されていないか確認（メーカー製UIに多い） |
| 広告が出ない | 数分待って再試行。テスト広告は在庫切れになりません |

### 認証が通らないとき（`not authorized`）

**ケーブルもドライバも正常です。** 「USBデバッグを許可しますか？」の
記録だけが問題なので、記録を消してやり直します。

1. **端末のロックを解除したままにする**（**ロック画面ではダイアログが出ません**）
2. 開発者向けオプション → **「USBデバッグの認証を取り消す」**
   （過去に一度「拒否」していると**二度と聞かれません**。取り消すと復活します）
3. **USBを抜いて挿し直す**
4. **「常に許可する」にチェック** → **許可**

確認は `adb devices`。`unauthorized` が **`device`** に変われば成功です。

```bash
%LOCALAPPDATA%\Android\Sdk\platform-toolsdb.exe devices
```

**どこで止まっても、ターミナルの出力か画面の写真をそのまま貼ってください。**
