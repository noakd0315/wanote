## 🔴 輸出コンプライアンス（要調査・実登録前に決着させること）

**PM判断: 2026-08-16、その場で答えず調査フェーズを設けることにした。**

TestFlight にビルドを配信するだけでも、`ITSAppUsesNonExemptEncryption`
（またはApp Store Connect上の同等の設問）への回答が要る。実登録では
避けて通れない。

### なぜ即答できないか

Apple の設問は、書類提出が必要な条件をこう書いている。

> 標準的な暗号化アルゴリズム（Appleのオペレーティングシステム内の暗号化を
> 使用したり、それにアクセスをしていないアルゴリズム）

このアプリの実態:

| | 判定 |
|---|---|
| 独自・非標準のアルゴリズム | **無し**（自前実装はゼロ） |
| `flutter_secure_storage` | iOSキーチェーンを使用 → 該当しない |
| HTTPS/TLS 全般 | 通信保護のみ |
| 🔴 **Firebase SDK（特に Firestore）** | **gRPC/BoringSSL を同梱**しており、Apple のネットワーク層をそのまま使っていない |

最後の1行が論点。**「標準アルゴリズムだが Apple OS の暗号化ではない実装」**
に文言上は当てはまり得る。Firebase を使うアプリの大半は免除として申告して
いるが、それは慣行であって、設問を厳密に読むと自明ではない。

### 決着させるべきこと

- [ ] 免除に該当するか（該当類型：「認証のためだけの使用」等）
- [ ] 該当するなら `ITSAppUsesNonExemptEncryption = false` を `Info.plist` へ
      （毎ビルドの質問が消え、CIがそのまま配信できる）
- [ ] 該当しないなら **CCATS または ERN の取得**。BIS への申請で**数週間**
- [ ] フランス市場に出すなら別途宣誓書

### 日程への影響

🔴 **書類が必要と判断した場合、取得に数週間かかる。** 9/30 の締切から逆算
すると、**Play の「12人×14日」と並ぶ律速になり得る。** 実登録の直前に着手
すると間に合わない。

**これは輸出規制の法的申告であり、PMの責任範囲。** 判断がつかない場合は
Apple のサポートか専門家に確認すること。
