# A. すぐ見られるもの（Android / 現行iPhoneビルド）

## A-1. プラン切り替えで落ちない

**これが今回いちばん大きい修正です。**

1. 設定 → **プラン変更** を開く
2. **落ちないこと**
3. 「プランのご購入は現在準備中です」と出ること

RevenueCatのキーがまだ入っていないビルドなので、この文言が正です。
「接続をご確認ください」と出たら**別の不具合**なので教えてください。

## A-2. 薬の記録から予防医療の履歴が見られる

1. 医療 → **投薬** タブ
2. 下の「予防医療」セクションの行の**名前をタップ**
3. → **投与履歴**が開くこと（以前は編集画面が開いていました）
4. 行の **+** は今まで通り「1回分を記録」

## A-3. 体重グラフの期間ボタン

1. 体重の記録 → グラフ
2. **3か月／6か月／1年／すべて** の4つ
3. **タップしてもボタンの幅が動かないこと**（チェックマークが消えました）
4. 「すべて」で、いちばん古い記録から表示されること

## A-4. 排尿の量

1. トイレ記録 → **排尿を記録**
2. 色の下に **量（少ない・普通・多い）**
3. 保存 → 一覧に「量：〜」が出ること

## A-5. 排尿の詳細画面

1. トイレ記録の一覧で、**排尿の行をタップ**（以前は反応しませんでした）
2. 日時・色・量・場所が並ぶこと
3. 下の **AI相談** ボタン → 相談画面にこの記録が添付されて開くこと
4. 排便の行も同じく詳細が開き、AI相談ボタンがあること

## A-6. トイレ記録の期間絞り込み

1. トイレ記録の一覧の上に **1週間／1か月／3か月／すべて**
2. 既定は **1か月**
3. 切り替えで件数が変わること

## A-7. トイレの警告が1か月以内になった

確認しづらい項目です。**血便疑いの記録を1件入れて**、警告バナーが出る
ことだけ見てください。1か月より古い記録では**出なくなる**のが今回の
修正ですが、古い記録を作るには日付を手で戻す必要があります。

## A-8. AIの残り回数

1. **AI相談** と **給餌量** の画面上部に
   「今月の無料利用 残り◯回／5回」
2. 1回使うと**その場で数字が減ること**
3. **AIレポートには出ません**（サブスク専用で無料回数を使わないため。
   ここに出すと「5回残っているのに使えない」ことになります）

## A-9. ローディングがwanoteアイコンに

読み込み中の表示が、灰色のくるくるから **wanoteアイコンの明滅** に
変わっています。起動直後・一覧の読み込み・証明書の表示など。

※ ボタンの中の小さいくるくるは**そのまま**です（アイコンが潰れるため）。

## A-10. 証明書は種別ごとに最新だけ

1. 医療 → **証明書** タブ
2. 同じ予防プログラムの証明書が複数ある場合、**最新の1件だけ**
3. 上に「過去の証明書 ◯件は非表示です」と出ること
4. 右上のフィルタボタン、または「過去の証明書も表示」で**全部出ること**

狂犬病と混合ワクチンは**別々に残ります**（受付で両方求められるため）。

## A-11. OCRの要確認マーク

1. 予防医療の記録 → 証明書を撮影
2. OCRが埋めた項目に **「要確認」** が付くこと
   （接種日・次回予定日・病院名・ワクチン名）
3. その項目を**自分で直すとマークが消えること**

## A-12. 履歴コピー

**通院・投薬・予防医療の3つ**で確認してください。

1. 新規作成の画面を開く
2. いちばん上の **「過去の記録から入力」**
3. 過去の記録が最大10件出る → 選ぶ
4. 内容が入り、**日付は今日のまま**であること
   （日付までコピーすると「いつ起きたか」が壊れるため、意図的です）
5. **編集画面には出ません**（上書きになってしまうため）

## A-13. ペットのサイズ

1. ホーム → **ペット名をタップ**（＝A-14）
2. 下の方に **サイズ（任意）**：首まわり・胴まわり・着丈
3. **「測り方」** → 図解と番号付きの説明が出ること
4. 入力して保存 → 開き直して**残っていること**
5. 英語表示にすると **単位が in（インチ）** になり、
   数値が換算されること（保存はcmのままです）

## A-14. ホームからペット編集

ホームの**ペット名（鉛筆アイコン付き）**をタップ → 編集画面。

# B. iOS再ビルド後でないと確認できないもの

## B-1. iPhoneでリマインダーが発動する

`AppDelegate` に通知デリゲートの設定が抜けていたのが原因です。
Androidには無い、iOS固有の必須設定でした。

1. 投薬か予防医療でリマインダーをON、**数分後の時刻**にする
2. アプリを**閉じて**待つ
3. 通知が来ること
4. アプリを**開いたまま**でも来ること（こちらが今回直した側です）

## B-2. カメラ・写真ピッカーが日本語になる

アプリが「英語専用」としてiOSに申告されていたため、OSが出す画面が
すべて英語になっていました。

1. 証明書やペット写真で**カメラ／写真ライブラリ**を開く
2. 「キャンセル」「写真を使用」などが**日本語**であること

※ **端末の言語**に追従します（アプリ内の言語設定ではありません）。
iOSの仕様上こうなります。複数言語を申告したことで、
**設定 → wanote → 言語** で個別に選べるようにもなります。

※ カメラ許可ダイアログの文面（「ワクチン証明書や〜」）は
**まだ日本語固定**です。英語化は別作業として残しています（下記）。
